# Project 43: The Telemetry-to-Simulation Loop

This repository contains a complete, open-source vehicle dynamics workflow. It bridges the gap between virtual racing and physics-based simulation. 

By utilizing raw telemetry and physics-based math, we can determine exactly how much lap time is being lost to aerodynamic drag, tire scrub, and wheelspin, rather than tuning purely by "feel."

## 📦 What's Inside (Flat Directory)
All files are kept in the root directory so they can be run immediately on any machine without altering script paths.

- **`LateModel43.mo`**: The OpenModelica physics model that calculates Delta-T (Work/Power) and sensitivities.
- **`clean_lap.py`**: The Python script that parses 13 channels from raw MoTeC data into a clean format.
- **`laptimeoswego.csv`**: A sample raw telemetry export.
- **`oswego_table.txt`**: The cleaned telemetry table generated by the Python script, ready to feed into OpenModelica.
- **`CarMod` (folder)**: The complete Assetto Corsa vehicle mod. (Download the release `.zip` below to get the full packaged car).

## 🚀 Download the Car Mod

## 🛠️ Quick Start Workflow
1. Put all files in a single folder (e.g., `C:\Simulation`).
2. Run `python clean_lap.py` to generate the `oswego_table.txt`.
3. Open `LateModel43.mo` in OMEdit and simulate to view the Delta-T physics.
